# M3 — The closed loop

**Goal.** Advice changes traffic, traffic changes link state, link state changes the next
observations. Demonstrate the oscillation result at realistic scale rather than in a toy.

**Depends on.** M1, M2. **Blocks.** M5–M9.
**Size.** Medium.

---

## Deliverables

### 1. `core/hosts.py` — the host population

N hosts per (src, dst, SLA) scope. Each host independently samples a path set from the
published advisory, generates traffic, and reports what it experienced. Configurable:
population size, SLA mix, arrival/departure, and a **defector fraction** that ignores the
advisory and plays greedy (this is the PAS v3 adversary taxonomy; wire the hook now, the
classes come in M6).

Sampling is independent by design. The realised split concentrates on the intended split
at `O(1/√N)` with no coordination, and that property is what the whole stochastic-advisory
argument rests on. Test it directly.

### 2. Loop closure

`advisory → host sampling → per-link offered load → link state → observations → advisory`.

Advisory application is **delayed by the model's decision latency**. A decision taken 800
simulated ms after the state it was computed from is applied against the state that exists
800 ms later. Invariant 3, made concrete.

### 3. Multi-scope

Many (src, dst) pairs active simultaneously, sharing links. Cross-scope coupling through
shared bottlenecks is where the interesting behaviour lives and where a single-scope
harness would mislead.

### 4. `instrument/detectors.py` (first cut) — oscillation

Oscillation index: spectral peak dominance restricted to the fast band, excluding slow
environmental drift. The existing implementation in `conformance` is correct in principle;
port it, and note in the code why the fast-band restriction exists (environment tracking is
not oscillation, and an earlier version conflated them).

---

## Acceptance criteria

- [ ] Greedy reference model oscillates at `realistic` scale, oscillation index > 0.5
- [ ] Stochastic reference does not, index < 0.15, same scenario and seed
- [ ] Realised split matches intended within the `1/√N` envelope at N = 100, 1k, 10k
- [ ] Decision latency demonstrably shifts application time; a slow model is measurably worse
- [ ] Multi-scope run with ≥ 100 concurrent scopes over `realistic` completes in budget
- [ ] Defector fraction hook exists and a 20% always-greedy population changes the outcome
- [ ] Whole loop deterministic from seed

## Must not break

Determinism. Invariant 3.

## Notes

**This milestone contains the project's headline result.** The figure is link utilisation
over time, ranked-advice versus sampled-advice, at realistic scale. If it does not
reproduce here, that is the most important negative finding the project can produce and it
must be reported, not tuned away.
