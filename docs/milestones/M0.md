# M0 — Foundation reset

**Goal.** Restructure the repo into the target layout with zero behaviour change, so that
every later milestone lands in the right place instead of being moved later.

**Depends on.** Nothing. **Blocks.** Everything.
**Size.** Small. One or two sessions.

---

## Deliverables

1. **Package restructure.** `scionfit` becomes `scionarena`, with the existing code moved:
   - `interface.py` → `exposure/contracts.py` (unchanged content)
   - `env/world.py` → `backends/analytical.py` (unchanged for now; rewritten in M1)
   - `probes/`, `report.py`, `runner.py` → `conformance/`
   - `reference/` → `reference/` (top level; used by every front-end)
   - empty packages with docstrings for `core/`, `instrument/`, `bench/`, `gym/`, `agent/`,
     `deploy/`, so the shape is visible from the first commit

2. **Import discipline enforced in CI.** Add `import-linter` with the contract:
   ```
   core  <-  exposure  <-  {conformance, bench, gym, agent, deploy}
   ```
   plus a rule that nothing under `reference/` or any user model imports `scionarena.core`.
   A violation must fail the build, not a review.

3. **Toolchain.** `mypy --strict` on `core/` and `exposure/` (both nearly empty, so it is
   free to adopt now and expensive later). `ruff` format in addition to lint. Pre-commit
   config. CI matrix on 3.11 / 3.12 / 3.13.

4. **Docs skeleton.** `docs/adr/0001-record-architecture-decisions.md`,
   `docs/OPEN_QUESTIONS.md` seeded with Q1–Q6 from HANDOFF §8, `VENDORED.md`,
   `benchmarks/` with an empty `baseline.json`.

5. **Determinism harness.** `core/trace.py` with a `TraceHash` helper and one test
   asserting that the existing conformance run over a fixed seed produces a stable hash.
   This is the tripwire for invariant 4 and it must exist before M1 adds any state.

---

## Acceptance criteria

- [ ] All 34 existing tests pass unmodified except for import paths
- [ ] `ruff check`, `ruff format --check`, `mypy --strict src/scionarena/core src/scionarena/exposure`, `pytest`, `lint-imports` all green in CI
- [ ] `scionarena conformance check reference` reproduces the v0.1 verdict exactly
- [ ] `python -m scionarena.conformance.cli compare` still discriminates
- [ ] The trace hash test passes twice in a row with the same value
- [ ] A deliberately added illegal import (`core` importing `conformance`) fails CI

## Must not break

The `PathModel` protocol signatures. The `DECLARED_ABSENT` / `FALSE_CLAIM` semantics. The
cross-model discrimination matrix.

## Notes

Resist improving anything while moving it. A restructure PR that also changes behaviour
cannot be reviewed. If you find a bug during the move, note it in the PR and fix it in a
follow-up.
