# M2 — Exposure layer: what the model can see and do

**Goal.** The model learns about the network **only** through tools and streams, every one
of which costs something. This is the layer that makes the project an agent harness rather
than a simulator.

**Depends on.** M1. **Blocks.** M3–M9.
**Size.** Large.

---

## Deliverables

### 1. `exposure/tools.py` — the tool registry

Tools with JSON schemas (usable directly as LLM function definitions), a cost model, and
rate limits. Minimum set for v0, chosen so the fourth tool requires no changes elsewhere:

| tool | returns | cost |
|---|---|---|
| `query_paths(src, dst, limit)` | path set with beacon metadata | query latency, path-server rate limit |
| `probe_path(path_id, kind)` | one measurement | bandwidth + wall-clock; SCMP rate limit per border router |
| `get_history(filter, since, until)` | raw past events | wall-clock proportional to volume returned |
| `subscribe(stream, filter)` | push feed handle | ongoing bandwidth |
| `publish_advisory(scope, weights, meta)` | ack | none, but it changes the world |

`kind` distinguishes cheap latency probes from expensive bandwidth tests. Costs must be
differentiated or budget reasoning is trivial.

**Every tool call is logged with arguments, return size, cost, and wall-clock.** That log
is the substrate of M4's operational metrics and M8's memory tests.

### 2. `exposure/streams.py` — observation feeds

Beacon feed, telemetry feed, path-server responses. Push or pull, both supported. Streams
deliver **raw events**. No aggregation, no windowing, no derived features. Invariant 1.

### 3. `exposure/budget.py` — cost enforcement

Probe budget, wall-clock budget, optional compute/token budget. Exhaustion is a normal
condition the model must handle, not an exception that ends the episode. Record what the
model does when it runs out; that is a measured behaviour.

### 4. `exposure/session.py` — one model, one episode

The single object every front-end drives. Holds the model's view, its budgets, its log
position. Enforces that the model cannot reach `core/`.

### 5. `exposure/contracts.py` — extend the protocol

Keep the existing four methods. Add an optional agentic entry point:

```python
class PathModel(Protocol):
    capabilities: Capabilities

    def reset(self, topo, seed=0) -> None: ...
    def observe(self, obs, topo) -> None: ...
    def predict(self, topo, paths, horizon_s=0.0, demand=None) -> Mapping[str, Prediction]: ...
    def advise(self, topo, paths, sla, n_hosts=1) -> Advisory: ...


class ToolUsingModel(PathModel, Protocol):
    def act(self, session: Session, deadline_s: float) -> None: ...
```

A model implementing only `PathModel` is driven in a fixed observe/predict/advise cycle.
A `ToolUsingModel` gets the raw session and decides for itself what to call. Both must
work; the second is the point.

Add capability flags: `uses_tools`, `manages_own_memory`, `respects_deadline`.

## Acceptance criteria

- [x] A model with no tool calls gets no information beyond the initial snapshot
- [x] Probe rate limits enforced per border router; violations rejected, not silently dropped
- [x] Budget exhaustion is survivable and recorded
- [x] Tool schemas validate as OpenAI/Anthropic function definitions without modification
- [x] The raw event log replays to an identical session state
- [x] Import-linter proves no model can reach `core/`
- [x] The existing four reference models run unchanged through `Session`
- [x] Adding a sixth tool touches only `tools.py` and its test

## Must not break

Invariant 1 (no harness-side summarisation). Invariant 2 (costs are charged). The existing
`PathModel` signatures.

## Notes

The temptation will be to give the model a convenient pre-digested view because it makes
the reference models simpler. Refuse. Convenience here destroys the memory and context-rot
experiments in M8, which are a large part of why this project exists.

Four things found while building it that later milestones have to carry:

1. **The border-router key had to be the interface, not the AS.** Keying the SCMP limit
   on the AS of the first egress interface made every path out of one source share a
   single allowance, so "spread your probes across border routers" — the only mitigation
   the network actually offers a model — was unavailable. The key is
   `br:<iface_name>`; ADR 0008 decision 4 says so explicitly because it is easy to
   coarsen again by accident.
2. **Invariants 2 and 3 are enforced by one code path.** Cost is computed from the
   payload and charged in the same function that advances the world, so a tool cannot be
   free and cannot be instantaneous without someone deleting both together. New tools
   inherit this; a new tool that calls `_advance` itself must also set `_prepaid_s`, as
   `probe_path(kind="bandwidth")` does for its two seconds.
3. **Runtime import checks cannot prove the layering here.** `scionarena/__init__.py`
   eagerly imports `conformance`, so importing *any* submodule loads the whole world and
   a `sys.modules` assertion always fails. The static AST check plus the import-linter
   contract are the real proof; do not reintroduce the subprocess version.
4. **Beacon age is derived from expiry, not from the segment store.** `PathRef`
   components are structural ids, not store indices, so indexing the store with them is
   wrong (it raised `IndexError` on the first realistic scope). Age is
   `lifetime_s - (expiry_s - now)`. `SegmentStore.last_resigned` exists for the same
   reason: the beacon feed needs *which* segments were re-signed, and rescanning per step
   is O(n_segments) at a tier where the step has to stay cheap.

Charging the model's own thinking time is off by default (`charge_real_time=False`)
because real elapsed seconds are not reproducible and invariant 4 is about the substrate.
`gym` and `bench` turn it on when realism is the point; until then `Stopwatch(fixed_s=...)`
gives tests a deterministic nonzero decision latency.
