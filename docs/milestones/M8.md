# M8 — Agent harness

**Goal.** Run an LLM agent against the network with no human in the loop, and measure the
things that only break at agent scale: memory, context degradation, latency, tool
economics.

**Depends on.** M2, M4. **Parallel with.** M5–M7.
**Size.** Large. The most novel milestone.

---

## Deliverables

### 1. `agent/loop.py` — the agent loop

Provider-agnostic. Tool schemas straight from `exposure/tools.py` with no translation
layer. One iteration: deliver new events, let the model call tools until it acts or the
deadline expires, apply the action, advance the world by however long it actually took.

**The harness does not manage context.** It hands the model the raw event delta and the
model decides what to keep, summarise, or discard. If the model wants a summary it writes
one itself, and that decision is recorded and measured. This is invariant 1 at its most
consequential and it is the reason the project is not just another simulator.

### 2. `agent/memory.py` — measurement, not provision

Scaffolds the model may *choose* to use, each opt-in and each instrumented: scratchpad,
retrieval index, explicit compaction. What is measured: what the model retained, what it
discarded, whether performance survived the discarding, and footprint over time.

A model that manages memory badly must be *allowed* to, or the experiment is rigged.

### 3. `agent/experiments/` — the AI-behaviour experiments

| experiment | design |
|---|---|
| **context rot** | fixed task, history grows 10^3 → 10^6 events; plot performance against length. Inject distractors (stale, irrelevant, superseded) and measure whether relevant recent information survives. |
| **latency** | vary the model's real decision time; measure the cost of thinking longer against a network that does not wait. There is an optimum and it is not zero. |
| **tool economics** | information gained per unit cost versus a random-probing control and an oracle-probing upper bound |
| **memory ablation** | same model with and without each scaffold |
| **overfit** | train on one topology partition and traffic regime, evaluate on a disjoint one |
| **prompt sensitivity** | same model, differently phrased task specs; variance is a reported property |

**Context rot is the headline experiment of this milestone.** As far as we know nobody has
measured it in a closed-loop network control setting, and the setting is unusually good for
it: the ground truth is known, the history is enormous, and the task runs for hours.

### 4. `agent/providers/`

Adapters for the major APIs plus a local-model path. Deterministic replay of a recorded
agent trace, so an experiment can be re-analysed without re-paying for inference.

### 5. Cost accounting

Tokens, wall-clock, money. Reported alongside task performance, because an agent that wins
at 100x the cost has not won.

---

## Acceptance criteria

- [ ] An LLM agent completes a `realistic` episode end to end, unassisted
- [ ] Context-rot curve produced for at least two models
- [ ] Latency experiment shows a non-trivial optimum
- [ ] Recorded traces replay deterministically with zero inference calls
- [ ] Cost per episode reported in tokens, seconds and currency
- [ ] Memory ablation shows a measurable difference between scaffolds
- [ ] Prompt-sensitivity variance reported, not hidden

## Must not break

Invariant 1 above all. If the harness ever silently summarises for the model, every result
in this milestone is void.

## Notes

Budget for real inference spend. The context-rot experiment at 10^6 events is not cheap,
and running it at 10^4 and extrapolating is not the same experiment.
